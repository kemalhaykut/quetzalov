# Quetzalov

Windows 11 için IPTV oynatıcı (Xtream Codes uyumlu: sunucu + kullanıcı adı + şifre).

- Canlı TV (kategori → kanal listesi → önizleme + yayın akışı), Filmler, Diziler (sezon/bölüm)
- Arama, favoriler, "izlemeye devam et", kaldığın yerden devam
- mpv tabanlı oynatıcı: büyük önbellek, otomatik yeniden bağlanma, sorunsuz ileri/geri sarma
- Ses dili, altyazı, kalite (görüntü izi), görüntü oranı, hız seçimi
- Pencere önde kalsın (📌), mini oynatıcı, tam ekran, klavye kısayolları

Derleme: GitHub Actions (`.github/workflows/build.yml`) → Releases: `Quetzalov-Kurulum.exe` ve `Quetzalov-Tasinabilir.zip`.
Ayarlar ve hesap bilgileri: `%APPDATA%\Quetzalov`.
